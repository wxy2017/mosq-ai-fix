
 ##  文本校对工具（错字检查 + 语句润色）
  
  任意输入框按 F8 抓错别字和用词不当，按 F9 润色语句更得体通顺


### 【它是什么】
  在微信、网页、记事本等任意输入框打好字：
  - 按 F8，使用【免费】的智谱云端大模型（GLM-4-Flash）检查错别字和明显的用词不当（如"出了以上方法"应为"除了以上方法"），并弹窗列出
  - 按 F9，把当前语句改写得更得体、通顺、易理解（优先润色选中的文字；无选区则润色整个输入框内容），弹窗预览可微调后替换

### 【使用方法】
  1. 双击「mosq-ai-fix.exe」
  2. 点进输入框打好字 → 按 F8 检查错字 / 按 F9 润色语句 → 等 1~5 秒
  3. 检查：弹窗列出错误 → 点「一键修正」自动替换，或「关闭」放弃
  4. 润色：弹窗显示润色结果 → 可手动编辑微调 → 点「替换原文」回填，或「取消」放弃
     （没错误或输入框没文字时，提示约 1 秒自动消失）
  5. 两个热键均可改：用记事本打开 config\typo_config.ini，
     修改 [hotkey] 段的 key（检查，默认 F8）或 polish_key（润色，默认 F9）

### 【第一次使用：配置 API Key（免费）】
  1. 打开 https://open.bigmodel.cn 注册 → 头像 → API Keys → 新建
  2. 把 config\typo_config.example.ini 复制一份，改名为 typo_config.ini
  3. 用记事本打开 config\typo_config.ini，把 Key 填到 api_key= 后面
  4. 确认 enabled=true，保存，重新双击「mosq-ai-fix.exe」

### 【注意事项】
  - 请配置 API Key 后再使用，否则无法检查
  - 可自定义使用其他大模型
  - 本地开启VPN情况下，注意网络是否能访问
  - 未使用管理员权限运行时，部分输入框可能无法抓取文字
