========================================
  文本错字检查工具
  任意输入框按 F8，AI 帮你抓错别字
========================================

【它是什么】
  在微信、网页、记事本等任意输入框打好字，按 F8，
  云端大模型（智谱 GLM-4-Flash，免费）检查错别字并弹窗列出，
  点「一键修正」自动替换回去。
  无需安装 Python，双击即用；文本会上传云端，勿输入敏感内容。

【使用方法】
  1. 双击「错字检查.exe」
  2. 点进输入框打好字 → 按 F8 → 等 1~5 秒
  3. 弹窗列出错误 → 点「一键修正」自动替换，或「关闭」放弃
     （没错误或输入框没文字时，提示约 1 秒自动消失）

【第一次使用：配置 API Key（免费，约 3 分钟）】
  1. 打开 https://open.bigmodel.cn 注册 → 头像 → API Keys → 新建
  2. 复制 Key，用记事本打开 config\typo_config.ini，填到 api_key= 后面
  3. 确认 enabled=true，保存，重新双击「错字检查.exe」

【常用设置】
  [hotkey] key   触发热键，默认 F8
  timeout        AI 超时秒数，网络慢可调大
  max_text       单次最多检查字数（默认 500）
  [log] debug    true 生成 config\ai_debug.log 调用记录
  [ui] tray_tip  true 时一键修正后右下角弹"已修正"提醒（默认 false 不弹）

【能检查什么】
  同音形近字（因该→应该）、成语（按步就班→按部就班）、的地得、
  网络谐音（灰常→非常）等；已成通用词的流行语（yyds 等）不报。

【改完设置后】
  保存 config\typo_config.ini，重新双击「错字检查.exe」生效。
  （启动时会弹"是否允许"，点"是"即以管理员权限运行——
    这样 VSCode 等以管理员运行的软件才能用；点"否"也能启动，
    但此类软件里按 F8 无效）

【目录说明】
  错字检查.exe       启动程序（双击即用，已编译无需装任何环境，勿删）
  config\            配置目录（typo_config.ini、调试日志 ai_debug.log）
  src\               程序本体（typo_check.ahk 主脚本源码、bin\check_ai.exe
                     校对程序、check_ai.go 源码、lib\ 运行时与编译器），勿删；
                     改源码后需在 src\ 下重新编译成 bin\check_ai.exe
                     （改主脚本后用 Ahk2Exe 重编译错字检查.exe）
